# 雨云对象存储：S3兼容、只算上行流量，图床和远程附件到底该选哪个套餐

被对象存储劝退过的人，多半不是被技术劝退的，是被账单劝退的。请求次数单独计费、下行流量另算、跨区流量再叠一层、API 调用按万次收费——算到最后你会发现，最贵的成本是算账的时间。

雨云对象存储（ROS，Rain Object Storage）走的是另一条路：只对存储空间和流量收套餐费，一张价格表能看完。下面把它的计费逻辑、三种套餐的区别、用超之后的后果，以及接图床/远程附件时容易踩的坑一次说清楚。

## 对象存储不是网盘，先分清这件事

ROS 是雨云提供的一种海量文件存储服务，你可以通过网络随时上传、存储和访问数据，典型用途是静态资源托管、数据备份和文件分发。

它和百度网盘、阿里云盘那类产品不是一回事：

- **网盘面向人**，你在网页上拖文件、点分享、看缩略图。
- **对象存储面向程序**，每个对象靠唯一标识符寻址，没有目录层级的概念，访问方式是一条 URL 或者一次 API 调用。

雨云这套服务是 S3 兼容的，这意味着你不用学新东西。PicGo 一键传图、rclone 多端同步、Alist 挂载成网盘、Cloudreve 和兰空图床接存储策略、WordPress 用 Media Cloud 之类的插件把附件卸载到远端——这些工具只要支持 Amazon S3 协议，填上 endpoint、Access Key、Secret Key 就能用。

数据可靠性方面，官方文档写的是通过多副本机制保障数据安全，降低硬件故障风险。这不是什么独家技术，属于对象存储的标配做法。

## 计费规则：把"上行流量"这个词掰开说

雨云的文档里，上行流量指的是雨云向用户发送文件时产生的数据传输量，下行流量指的是雨云接收用户上传文件时的量。

这组命名和很多人的直觉是反的，所以直接看结论更省事：

- 你往存储桶里传文件 —— 不扣流量
- 别人从存储桶里下载文件 —— 扣流量
- 同一区域的云服务器用内网地址读写同区域的存储桶 —— 上下行都不计入

换句话说，**存的成本你认了，下载才计费，上传免费**。对图床、静态资源站这类"写得少、读得多"的场景，这个规则决定了它能不能用；对备份场景，读的次数本来就少，流量基本不是问题。

超出套餐之后按地区计费，标准不一样：

| 地区 | 流量超出 | 存储空间超出 |
| --- | --- | --- |
| 浙江宁波 | 0.1 元/GB | 0.5 元/GB |
| 湖北十堰 | 0.2 元/GB | 0.2 元/GB |

雨云产品页上还给了套餐内的折算参考：流量套餐内每 GB 约 0.05 元/月，存储套餐内每 GB 约 0.2 元/月。套餐买得越大，单价越低，这是套餐制的常规玩法。

有一件事必须先知道：**超出套餐用量后，默认是停止访问的，不是自动扣费。** 想继续用就得去控制台打开弹性计费开关，打开之后超出部分才按上面的标准扣费。不打开的话，量到了就停，这对怕账单失控的人是好事，对流量波动大的业务就要提前想好。

## 三种套餐，其实对应三种使用习惯

官方分的三类套餐，名字起得挺直白：存储优先、平衡、流量优先。判断方式也很简单——先看你的数据是"躺着"还是"跑着"。

**存储优先套餐（湖北十堰）**：存储配得大，流量配得小。100GB 存储只给 25GB 流量。适合做素材库、备份归档、视频原片存放这类场景：文件存进去之后很少被反复拉取，偶尔下载几次也够用。

**平衡套餐（湖北十堰）**：存储和流量 1:1。50GB 存储配 50GB 流量。适合一边存一边要分享的情况，比如把设计文件放云上、时不时发给客户，或者中小型网站的附件存储。

**流量优先套餐（浙江宁波）**：存储小而流量大。10GB 存储配 50GB 流量，10 元一个月。这是典型的图床套餐——博客图片总量可能就几个 GB，但每篇文章被访问都要拉一遍，流量消耗远大于存储占用。

如果你的网站有独立服务器，还有一个省钱细节：把云服务器和对象存储放在同一区域，走内网地址读写，流量直接不计。买之前先确认服务器落在哪个区域，别买到对面去了。

## 用超套餐会发生什么

这块的处理方式比"直接停机"人性化一点：

- 存储空间用超，且没开弹性计费 —— 禁用上传功能，已有文件下载不受影响
- 流量用超，且没开弹性计费 —— 禁用下载功能，文件仍然存在
- 弹性计费开关可以随时关掉；用量耗尽后，相应的上传或下载功能会在几分钟内自动停止，防止欠费一路滚下去

另外套餐可以弹性变更，升级补差价即可，也支持降级，官方说法是修改后实时生效。这对用量摸不准的人挺实用——先用小套餐跑一个月看看真实消耗，再决定要不要升。

## 从注册到跑起来，大致这几步

流程本身不复杂，真正的门槛在配置细节上。

1. **注册账号**。进控制台后建议把微信、手机号绑上，很多优惠券和积分任务跟绑定状态有关。
2. **购买或兑换一个存储实例**。实例是计费主体，一个 Access Key 管这个实例下所有存储桶，配额是共享的，不会出现"每个桶单独算"的浪费。
3. **创建存储桶**。命名规则比较严格：只能用小写字母、数字和短横线，首尾必须是小写字母或数字，至少 3 个字符，且全局唯一。
4. **决定要不要开公共访问**。默认是关闭的，此时必须带 Access Key 和 Secret Key 才能读写。做图床或者公开下载资源，就得去"信息与监控"里把公共访问打开；不想公开的，可以给单个文件生成预签名临时链接。
5. **把参数填进客户端**。endpoint、Access Key、Secret Key 三样拿到手，PicGo、S3Browser、rclone 这类工具照填就行。
6. **要绑定自己域名的话**，域名的 CNAME 记录指向 `cn-sy1.rains3.com`。注意域名需要先完成 ICP 备案；SSL 证书可以走雨云的证书中心同步。不绑定域名也能用，系统默认给了访问域名。

访问方式上，雨云同时兼容 PathStyle 和 VirtualHost 两种模式。以共用域名 `rains3.com` 为例，前者形如 `rains3.com/bucket`，后者形如 `bucket.rains3.com`。部分老工具只认其中一种，配的时候留意一下。

## 几个新手一定会碰上的坑

这些是官方帮助文档里明确列出的问题，不是猜的：

**开启防盗链后图片突然访问不了。** 需要在 Referer 白名单里把 `app.rainyun.com` 加进去，否则管理面板自己都读不到文件。

**JS 文件加载后不生效。** 有些情况服务器返回的 Content-Type 是 octet-stream，浏览器识别成纯文本，脚本自然不执行。解决办法是在上传时主动把 Content-Type 设为 js。这个问题在大多数 S3 服务上都存在，不算雨云独有。

**文件夹下不下来。** 对象存储没有真正的"文件夹"概念，界面上下不了整个目录，得用 rclone 或 S3Browser 这类工具批量拉。

**存储桶默认不公开。** 很多人把图片传完发现链接打不开，原因就是公共访问没开，或者本月流量已经用完被禁用了下载。

安全方面还有一层 WAF：Referer 防盗链防别人白嫖图片、全局和单 IP 速率限制、超限后触发 JS 验证挡 CC 攻击、IP 黑白名单控制来源。要不要全开取决于你的内容是否会被恶意刷流量——对于公开图床，防盗链基本是必开的。

## 便宜的部分：折扣、积分和免费额度

成本这块有几条明确可查的路径：

**首月折扣。** 通过邀请链接注册并绑定微信的用户通常会拿到一张首月 5 折优惠券，这是雨云论坛和多个教程都提到的固定新用户福利。券的面额、有效期和适用产品以你账号里优惠券页面的实际显示为准——这类信息变动快，别人的截图不能当依据。

**长期付费折扣。** 季付、半年付、年付都有对应折扣，用得稳的话月付其实是最贵的选择。

**消费返积分。** 购买产品会按金额返还一定比例的积分，官方产品页写的是 10% 以上。积分用途比较灵活：兑换优惠券、给产品免费续期，或者按比例提现。有件事要注意——**领取产品积分后就不能退订了**，领之前先确认自己要用下去。

**积分兑换免费额度。** 雨云的积分机制里，完成每日签到、绑定信息、加群等任务可以攒积分，然后在积分商城中兑换免费产品，免费产品也支持用积分续期。库存不是常备的，通常每天固定时段刷新，抢不到属于正常情况。

**退订政策。** 雨云产品提供 7 天无理由退订，期间可以自助操作。对不确定稳定性的用户来说，先买一个月实测再决定续不续，是风险最低的路径。

## 谁适合用，谁可以先放一放

适合的场景比较明确：博客图床、网站静态资源托管（CSS/JS/图片）、服务器附件卸载、跨设备备份同步、个人网盘挂载。这些场景的共同点是数据量不大、以读为主、对单次响应速度要求没那么极端。10 元到 40 元一个月的档位基本能覆盖个人和中小站点的全部需求。

需要谨慎的情况也说清楚：如果你要做的是生产环境的核心业务存储，或者对可用性 SLA、跨地域容灾、图片实时处理（缩放、裁剪、格式转换）有硬性要求，那么需要先确认雨云是否提供对应能力——目前公开文档里没有看到图片处理类功能的说明，绑定的区域选择也有限，没有开到多地域。这类需求更适合拿大厂的完整对象存储方案做对比后再决定。

至于"要不要先试免费额度再买"这个问题，答案是值得。对象存储这种基础设施，价格表看得再明白，也不如自己传一批文件、接一个工具、跑一个月的真实流量数据来得准。
